## Простыми словами

- **Вида четыре** (Ф2.17-2, 19.10.2026): палитры «Сумерки» (по умолчанию,
  лавандовый акцент) и «Закат» (мандариновый) × светлая и тёмная тема, шрифт
  Rubik. Выбор — в Настройках («Цвет», «Режим»), по умолчанию — тема
  телефона.
- **Всё оформление уже собрано в одном месте:** цвета обеих тем — в
  `tokens.css`, кнопки, карточки, шторки и списки — около 20 общих
  компонентов, иконки — свой набор из 54 штук. Поэтому редизайн — это правка
  токенов и компонентов, а не 22 разделов.
- **Чего нет — всё, что строит Ф2:** экраны расписания, карточек учеников,
  учёта уроков, рефералки, тарифа, «Мои уроки», а под них — около 15
  компонентов (сетка дня и недели, выбор даты и времени, тумблер, тост
  «Вернуть»…) и около 25 иконок (календарь, ученики, подарок, ссылка,
  повтор…). Список — §6, по экранам.

## 3. Общие компоненты

**`src/shared/ui`** — на токенах, проверяются сторожем; живая витрина всех в
обеих темах — `/dev/ui` (только `npm run dev`):

| Компонент | Для чего |
|---|---|
| `Button` | главная / вторичная / тихая / опасная; загрузка |

| `Sheet` · `Picker` | шторка снизу (на компьютере — панель справа) · выбор из списка в шторке |
| `TabPicker` · `ChoiceGroup` | вкладки / сегмент · выбор одного значения (уровень, скорость) |
| `Reveal` · `HowItWorks` | раскрывашка · свёрнутое пояснение «как это работает» |
| `Loading` / `RowsSkeleton` · `LoadError` · `Thinking` | ожидание экрана · ошибка с повтором · «AI думает» |
| `UndoToast` | тост с откатом «… · Вернуть» и полоской времени (Ф2.5; дальше — перенос урока, t5) |
| `BackButton` / `BackHeader` | одна кнопка «назад» на всё приложение |
| `Chat` | окно переписки, пузыри, плавающая капсула ввода (Диалог, AI-квесты) |
| `layouts` | раскладки: `CenterColumn` (упражнение), `ReadingColumn` (текст + перевод сбоку), `ListDetail` (список + подробности) |
| `roundKeys` | клавиатура в упражнениях: 1–4, Enter, Esc |
| `ThemePicker` | «Как в системе / Светлая / Тёмная» — пока только в админке |
| `OpenPage` · `AppLink` · `Brand` · `Confetti` · `icons` | рамка открытой страницы · ссылка · логотип · праздник · иконки |

**Старые общие куски с предметной логикой** (`src/components`, переезжают в
разделы в Ф3), заметные в макетах: `RoundResult` / `RoundProgress` (итог и
прогресс раунда), `exercises` (варианты, пропуск, банк слов, ввод),
`WordSheet` (перевод слова по тапу), `MarkableText` + шторки разбора текста,
`EnergyBar` (полоска ⚡), `GuidedNext` («дальше» в «Начать занятие»),
`FeedbackSheet` (отзыв), `ChartView` (графики IELTS).

## 7. Разнобой и решения к редизайну (Ф2.17, Ф5.0)

- ✅ **Казахские буквы** ә ғ қ ң ө ұ ү һ: в Onest их не было (кроме і) —
  имя «Нұрсұлтан» рисовалось двумя шрифтами. С Ф2.17-2 шрифт — Rubik, все 18
  букв есть в файлах, которые браузер для них качает (проверка —
