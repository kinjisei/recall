# Переход на платный Gemini

> Инструкция владельцу (PLAN.md Ф1.6). Прогнана на тестовом стенде 28.09.2026 —
> что именно проверено, в конце. Цены и правила Google меняются без
> предупреждения: перед переходом открой ссылки глазами.

## Простыми словами

Сейчас AI работает на бесплатных лимитах Google. Они маленькие и общие на
весь проект: у каждой «умной» модели (gemini-3.6-flash, 3.5-flash,
2.5-flash) около **20 запросов в сутки на всех**. Когда они кончаются,
Диалог отвечает запасной моделью Groq — она попроще.

Переход на платный тариф — это **новый ключ Google из отдельного проекта с
картой** и **одна настройка** на Vercel. Код менять не нужно, откат — вернуть
старый ключ.

## Когда переходить

Смотри `/admin` → блок **«Расход AI»** → «Сегодня» и «7 дн»:

- у gemini-3.6-flash / 3.5-flash / 2.5-flash регулярно «20 из 20» и «отказ по
  квоте» — бесплатный запас Google кончается;
- в «Вызовы сегодня» у Диалога растёт «без ответа», а в попытках всё чаще
  отвечает `openai/gpt-oss-120b` (запасная модель Groq) — люди получают
  ответы слабее;
- или раньше, если качество запасной модели тебя не устраивает.

## Что важно знать до

1. **Карта привязывается к ПРОЕКТУ Google Cloud.** Привязал к проекту — все
   модели Gemini этого проекта платные сразу, бесплатной дневной квоты у них
   больше нет. Исключение — Gemma (`gemma-4-31b-it`): платного тарифа у неё
   нет, она остаётся бесплатной
   ([pricing](https://ai.google.dev/gemini-api/docs/pricing)).
2. Поэтому — **отдельный проект с картой**. Текущий бесплатный проект не
   трогай: к его ключу откатываемся. Если один и тот же платёжный аккаунт
   привязать к обоим проектам, платными станут оба
   ([billing](https://ai.google.dev/gemini-api/docs/billing)).
3. С 1 апреля 2026 у платных тарифов Google есть обязательный месячный
   потолок трат — счёт «в космос» не улетит.
4. Цены за 1 млн токенов (вход / выход, на 24.07.2026): gemini-2.5-flash
   $0,30 / $2,50, gemini-3.6-flash $1,50 / $7,50 — в 5 раз дороже. Поэтому в
   платном режиме первой идёт 2.5-flash: это и делает настройка
   `RECALL_CHEAP_MODELS=1` (`api/_core.ts`).

## Шаги (~20 минут)

1. [console.cloud.google.com](https://console.cloud.google.com) → вверху
   список проектов → **New project** → имя `recall-paid` → Create.
2. Меню → **Billing** → привяжи платёжный аккаунт **только** к `recall-paid`.
3. [aistudio.google.com](https://aistudio.google.com) → **Get API key** →
   Create API key → выбери проект `recall-paid` → скопируй ключ.
4. Проверь ключ, не тратя ни одного запроса: в `.env.local` замени строку
   `GEMINI_API_KEY=…` на новый ключ и запусти
   `node scripts/check-ai-models.mjs` — все строки Gemini должны быть ✓
   (скрипт спрашивает только список моделей). Потом верни в `.env.local`
   старый ключ, если не хочешь, чтобы локальные проверки шли за деньги.
5. **Сохрани старый ключ** (менеджер паролей или заметка) — это откат.
6. [vercel.com](https://vercel.com) → проект → **Settings → Environment
   Variables**, окружение **Production**:
   - `GEMINI_API_KEY` → новый ключ;
   - добавь `RECALL_CHEAP_MODELS` = `1`.
7. **Deployments** → последний → **⋯ → Redeploy**. Без этого ничего не
   поменяется: переменные читает только новая сборка.
8. Проверка: открой Диалог, отправь реплику. Затем `/admin` → «Расход AI» →
   «Сегодня»: у **gemini-2.5-flash** появился расход, отказов по квоте нет.
   ⚠️ Смотри именно, **какая модель ответила**, а не «ответило ли вообще»:
   ответит и старая сборка — на прогоне 28.09 ровно так и вышло (см. ниже).
9. Через час загляни в AI Studio проекта `recall-paid` → Usage: запросы
   видны и там.

## Откат

Vercel → Environment Variables: `GEMINI_API_KEY` ← старый ключ, удалить
`RECALL_CHEAP_MODELS` → Redeploy. В `/admin` первой снова станет
gemini-3.6-flash.

## Прогон на тестовом стенде (28.09.2026)

Стенд — `npm run dev:test`: тот же код, что на проде (dev вызывает те же
обработчики `api/`), и тестовая база. Платного ключа у проекта пока нет,
поэтому прогнана вся процедура, кроме самой карты:

1. Сервер перезапущен с `RECALL_CHEAP_MODELS=1` (на Vercel это шаги 6–7).
2. `node scripts/smoke-ai-dev.mjs --expect-cheap` — одна настоящая реплика
   Диалога; в журнале первая попытка — `gemini-2.5-flash`, ответила она же.
   ✓ 8/8.
3. **Что поймал прогон:** в первый раз проверка покраснела — ответила
   gemini-3.6-flash. Причина: прежний сервер не остановился и продолжал
   отвечать, а новый (с настройкой) не смог занять порт. Ответ при этом
   пришёл — «ответило» ничего не доказывает. Отсюда пункт 8: смотреть,
   какая модель спрошена первой. На Vercel то же самое случится без
   Redeploy.

Проверить ключ заранее — `node scripts/check-ai-models.mjs` (шаг 4).
Проверить, что после перехода отвечает дешёвая модель, — блок «Расход AI»
(шаг 8) или на стенде `smoke-ai-dev.mjs --expect-cheap`.

## Если захочется «сначала бесплатно, потом платно»

Можно держать оба ключа: бесплатный первым, платный — когда бесплатный
отвечает «квота кончилась». Это экономит деньги, но это уже код (два ключа
и выбор между ними в `api/_core.ts`), а не настройка. Решать по цифрам блока
«Расход AI»: если платных запросов в сутки — единицы, игра не стоит свеч.
