# Учебник «Строитель А+Б» — план и решения

> Интерактивный учебник для владельца: как делать качественные продукты с помощью
> ИИ — весь жизненный цикл, от идеи до денег и постоянных клиентов. Весь материал
> разбирается на живом примере Recall. Решения согласованы грилингом 2026-07-25.

## Решения (не пересматривать без владельца)

- **Форма**: главы — markdown в `docs/textbook/chapters/`; читалка — HTML,
  собирается `node docs/textbook/build.mjs` из `shell/template.html` + глав +
  `glossary.json`. Публикуется **приватным артефактом claude.ai** (постоянная
  ссылка, обновлять ТОТ ЖЕ артефакт — favicon 📖, файл `build/index.html`).
  `build/local.html` — то же самое для открытия с компа двойным кликом.
  Ссылка артефакта (обновлять именно его, из другой сессии — параметром `url`):
  https://claude.ai/code/artifact/f9dbdd6e-5d49-4082-a0a0-ba8aedb29642
- **Оболочка умеет**: оглавление с прогрессом, закладка «Продолжить чтение»
  (localStorage), глоссарий (термин в тексте → карточка), плеер озвучки
  (системный голос: пауза, скорость 0.5–2×, назад/вперёд по предложениям,
  подсветка читаемого). MP3-аудиокниги НЕТ (осознанно, можно добавить потом).
- **Шаблон главы (5 блоков)**: 1) суть простыми словами (сквозная аналогия со
  стройкой) → 2) разбор на Recall: ✅ хорошо / ⚠️ забыли-нашли / 💡 можно лучше →
  3) термины в глоссарий → 4) чек-лист для нового проекта → 5) вопросы себе.
- **Каждая глава = свежий аудит кода по её теме.** Sonnet копает, Opus
  подтверждает только спорное, Haiku — механика. Находки: в главу — как живой
  пример, владельцу — в раздел «Находки на исправление» ниже.
- **Критик части**: после последней главы каждой части — воркер-критик ищет,
  чего в части не хватает для реальной жизни; найденное добавляем.
- **Язык**: простой русский, каждый термин объясняется, без канцелярита
  (скилл humanizer). Тексты пишет главная линия, не воркеры.
- **Модели**: каскад цены (правило владельца №6). Fable — только главная линия.

## Заходы (промпты копировать целиком)

Каждый заход заканчивается: `node docs/textbook/build.mjs` → обновить ТОТ ЖЕ
артефакт → обновить таблицу статусов выше → находки аудита в раздел ниже.

- **У1 (этот)**: план + оболочка + глава 1. Аудит главы 1 — проверка фактов по
  docs/истории (без воркеров: тема не про код).
- **У2**: «Учебник, заход У2: главы 2 „Идея и спрос“ и 3 „Планировка“ по
  docs/textbook/PLAN.md. Аудит: как Recall проверял спрос (monetization-draft,
  лендинг /teachers) и чем реальность разошлась с планами; для гл. 3 — сверка
  docs/ARCHITECTURE.md с реальным кодом (воркер Sonnet). Затем критик части I.»
- **У3**: «Учебник, заход У3: главы 4 „Фундамент“ и 5 „Код“. Аудит: структура
  src/ на отклонения от заявленной, дубли/мёртвый код, места без типов
  (2 воркера Sonnet, спорное — Opus).»
- **У4**: «Учебник, заход У4: главы 6 „Безопасность“ и 7 „Данные“. Аудит:
  свежий проход по RLS/грантам/RPC схемы и по клиентским запросам (Sonnet ×2,
  подтверждение находок — Opus; НЕ повторять уже задокументированные дыры —
  сверяться с docs/pentest-zahod18.md и историей CLAUDE.md).»
- **У5**: «Учебник, заход У5: главы 8 „Тесты и ревью“ и 9 „Дизайн и UX“. Аудит:
  какие фичи не покрыты смоуками; прогон scripts/ux-audit.mjs. Критик части II.»
- **У6**: «Учебник, заход У6: главы 10 „Карта сервисов“ и 11 „Деплой и
  эксплуатация“. Для гл. 10 — ресёрч тарифов сервисов (Sonnet, только
  первоисточники, по образцу docs/costs.md). Аудит гл. 11: что у Recall с
  мониторингом ошибок и бэкапами (честно: почти ничего — разобрать).»
- **У7**: «Учебник, заход У7: главы 12 „Нагрузка и траты“ и 13 „Юридика“.
  Гл. 12 — на базе docs/costs.md + свежая проверка лимитов. Гл. 13 — на базе
  захода 16 + ресёрч оформления ИП/налогов РК (Sonnet, первоисточники).
  Критик части III.»
- **У8**: «Учебник, заход У8: главы 14 „Цена и юнит-экономика“ и 15 „Лендинг“.
  Аудит: пересчёт юнит-экономики тарифов по costs.md; разбор /teachers и
  /pricing по скиллам copywriting/cro (что хорошо, что слабо).»
- **У9**: «Учебник, заход У9: главы 16 „Запуск и клиенты“ и 17 „Продажи и CRM“.
  Ресёрч каналов для маленьких продуктов (Sonnet). Разбор docs/tg-launch.md.»
- **У10**: «Учебник, заход У10: главы 18 „Удержание и метрики“ и 19 „Поддержка“.
  Аудит: какие метрики Recall уже собирает (activity_log, Vercel Analytics),
  чего не хватает для решений. Критик части IV.»
- **У11**: «Учебник, заход У11: глава 20а „Как разговаривать с ИИ“ — промпты,
  zero/few-shot, температура, top-p, RAG, fine-tuning, RLHF, контекстное окно.
  Все примеры — из реальных промптов Recall (api/, lib/). Ресёрч — по
  первоисточникам (доки Anthropic/Google).»
- **У12**: «Учебник, заход У12: глава 20б „Оркестр из ИИ“ — скиллы, MCP,
  агенты-воркеры, воркфлоу, „голос→текст→промпт“, Claude Code и его настройка,
  как сотрудники Anthropic используют ИИ (ресёрч по публикациям Anthropic).
  Финальный критик полноты ВСЕГО учебника.»

## Известные ограничения

- Озвучка обрывается при выключенном экране телефона (ограничение браузера).
  Решение при желании: MP3-аудиокнига отдельным заходом (edge-tts, бесплатно).
- Артефакт приватный, но при публикации ссылки доступ получит любой, кому её
  перешлют — в учебнике есть разборы безопасности Recall (дыры закрыты, но
  ссылку наружу не публиковать).
