## О2 — запросы к Supabase
Замер `scripts/measure-queries.mjs` (round-trip'ы по экранам; отсекает CORS-preflight).
Важно: видимое «всё ×2» оказалось preflight'ом (OPTIONS+запрос), не двойным
выполнением.

Главная: **19 → 15** реальных запросов, без дублей.
- `getDeckIds` — дедуп «в полёте» (звался 3× одновременно → 1 запрос к decks).
- `activity_log` — `loadHomeActivity` один запросом вместо трёх (стрик+неделя+сегодня).
- `AuthContext` — `user` стабилизирован по id (`useMemo`): гасит РЕАЛЬНЫЕ
  пере-фетчи при рефреше токена раз в час; дашбордные эффекты на `[user?.id]`.
- `TeacherPage` — `countSubmittedWorks` влит в `Promise.all`.

## О3 — рантайм/рендер
- `loadPackItems` — кэш обработанных паков на сессию: не прогонять map+фильтр по
  ~4600 словам на КАЖДЫЙ вход в игру (данные статичны).

Остальной рантайм признан чистым: `PracticePage` хоистит подкомпоненты, списки
грамматики на `useMemo`, таймер Спринта минимален с очисткой, `contextDict` —
кэш с эвикцией, слушатели чистятся, каскадов эффектов нет.

## Осознанно отложено (низкая отдача / риск)
- `TappableText` ре-рендерит все span при drag выделения фразы — ситуативно
  (длинные тексты); правильный фикс трогает тонкую pointer-логику из аудита
  багов (заход 1), риск регрессии > выигрыш.
- Полная мемоизация value/session в AuthContext — ре-рендер раз в час на
  рефреше токена, краткий, без пере-фетчей.

- Дубль `activity_log` на «Прогрессе»; отсутствие `.limit()` у материалов/карточек
  (форвард-лукинг, при росте данных).
