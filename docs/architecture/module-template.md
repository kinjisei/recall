# Шаблон описания модуля (`CLAUDE.md` папки)

> Форма — архитектура §3, зачем — журнал п.8 («описания живут рядом с кодом,
> отставать им запрещает проверка»). Готовые примеры:
> `src/features/homework/CLAUDE.md` (раздел с механикой в `lib/`),
> `src/domains/ai/CLAUDE.md` (домен).
>
> Скопируй блок ниже в `<папка модуля>/CLAUDE.md`, заполни, затем
> `npm run gen:docs` — он допишет блок generated.

~~~markdown
# <папка> — <что это, одной строкой>

## Простыми словами

<5–15 строк для владельца: что делает, зачем, как это видит человек. Без
жаргона: не «алгоритм FSRS», а «слово вернётся, когда начнёт забываться».
Цифры и честные ограничения — да, общие слова — нет (скилл humanizer).>

| Файл | Что там |
|---|---|
| `<файл>` | <назначение — по желанию: сам список файлов есть в блоке generated> |

## Правила, которые нельзя нарушить

- **<правило>** — почему; где в коде; какая проверка его держит.

## Как проверить

- `node scripts/<проверка>.mjs` — что именно проверяет (чистый, в CI / нужен
  `npm run dev:test`).

## Решения и почему

- <решение> — почему так, а не иначе (коротко; история — в git).

<!-- generated:start -->
<!-- generated:end -->
~~~

## Как вести описание

- **Изменил код модуля — измени описание в том же коммите.** Иначе сторож
  описаний не пропустит коммит, пока в сообщении нет «описание не меняется,
  потому что <причина>». Пересборка блока generated правкой не считается.
- **Блок generated руками не правят** — его пишет `npm run gen:docs` (файлы,
  адреса экранов, таблицы и RPC, AI-задачи, ключи localStorage, кто модулем
  пользуется). `npm run check` краснеет, если блок отстал от кода.
- **Модуль из `src/lib/` или `src/components/` с механикой раздела** —
  указатель в первых 20 строках файла: `// Описание: src/features/<раздел>/CLAUDE.md`.
  Тогда сторож требует правку именно этого описания, а генератор показывает
  файл в его блоке. Переехал файл в свой домен — указатель удаляется.
- **Одно правило — в одном описании.** В соседнем — ссылка
  («`features/billing/CLAUDE.md`, «Энергия»»), а не копия: две копии
  расходятся молча.
- **Не писать счёт проверок** («29/29»): он устаревает со следующим тестом.
  Писать, ЧТО проверка ловит.
- **Правка на месте**: поменялось поведение — переписывается правило, а не
  дописывается «а теперь по-другому» в конец.
