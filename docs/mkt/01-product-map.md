## 2. Двенадцать фактов, которые меняют маркетинг

Отсортированы по силе влияния.

**1. Роль преподавателя выдаётся только SQL-ом вручную.** UI-пути нет вообще, `TeacherPage` прямо пишет «попроси владельца». Любая реклама на репетиторов упирается в это: человек регистрируется и не видит студию. **Блокер №1 для B2B2C.**

**2. Четыре крупные фичи невидимы для самостоятельного ученика.** Задания, Письмо/IELTS, AI-квесты, Программа появляются, только если их назначил учитель. Пришедший по рекламе B2C-пользователь видит заметно более бедный продукт, чем мы будем описывать. **Блокер №1 для B2C.**

**3. Free-тариф = 5 реплик разговора в сутки.** Одна проверка письма съедает 2 из 5. Для «ежедневной практики речи с AI» этого объективно мало — надо либо честно проговаривать, либо менять экономику Free.

**4. Оплата ручная, автопродления нет.** Kaspi-перевод → ты руками включаешь план через `/admin`, «в тот же день, до суток». Каждый платящий клиент = ручная работа владельца, каждое продление = риск отвала.

**5. Аналитики нет.** Только Vercel Analytics (просмотры страниц). Ни одного кастомного события: регистрация → активация → оплата не считается ничем, кроме ручного SQL. **Начинать платный трафик без этого нельзя — мы не поймём, что сработало.**

**6. Регистрация закрыта белым списком** (`allowed_emails`, проверено живой пробой — `RECALL_NOT_INVITED`). UI регистрации готов, гейт стоит в БД. Открывается отдельным файлом `docs/open-registration.sql`.

**7. Открытие регистрации фармится.** Триал 14 дней = premium-квота каждому новому email. Confirm email уже включён (`mailer_autoconfirm: false` — проверено), это закрывает основной сценарий, но урезание триала до 12 действий/сутки — единственная вторая линия.

**8. «Материалов в месяц» — не то, что думает клиент.** Один материал = минимум 2 генерации (план + контент), правки — ещё по одной, генерация вопроса/графика для «Письма» списывается из того же пула. На тарифе 3900 ₸ это ~10–12 материалов, а в тексте написано «до 25 AI-материалов». **Это обещание надо переписать до запуска, иначе первые же платящие учителя поймают нас на расхождении.**

**9. Внешние квоты могут отказать раньше наших.** Приложение живёт на бесплатном тире Google/Groq. Возможен сценарий: у пользователя энергия есть, а AI не отвечает, потому что дневная квота всех моделей цепочки исчерпана. При росте это первое, что сломается.

**10. Vercel Hobby + приём оплаты = нарушение ToS.** Не техническая, а юридическая мина; активируется ростом видимости.

**11. Мы не продаём «Письмо».** Целая фича (IELTS с band-оценкой по 4 критериям) собрана 3 августа и не упомянута ни в CLAUDE.md, ни в текстах на сайте. При этом для репетитора проверка эссе — самая дорогая ручная работа. Это, возможно, **сильнейший аргумент продажи, который сейчас лежит мёртвым грузом.**

**12. Часть контента — витрина, но меньшая, чем казалось.** Пересчитано по коду и
данным: фильтр `isPlayable` (>3 слов, >28 символов, перевод длиннее 60) убирает из игр
**445 идиом из 911** — остальные 466 тренируются нормально. По всей английской базе
играбельны 4383 слова из 4844. То есть идиомы в рекламе упоминать можно; нельзя
говорить «все 911 в тренажёрах».

## 3. Что нельзя говорить в рекламе (текст ≠ реальность)

| Соблазн сказать | Реальность |

| «Безлимитный AI-репетитор» | 5 действий в день на Free |

| Цены 1490/3000/5000/12000 (из CLAUDE.md) | 1990/3900/6500/14990 |

## 4. Что делать до первого трафика (черновик, детализируется в заходе 15)

1. Путь «стать преподавателем» без SQL — заявка или автоматическая выдача роли.
2. Дать одиночному ученику доступ к квестам/письму (самоназначение) — иначе B2C-продукт наполовину невидим.
3. Открыть регистрацию + защита триала.
4. Минимальная аналитика воронки (события: регистрация, онбординг пройден, первое AI-действие, привязка к учителю, оплата).
5. Переписать обещание про материалы; добавить «Письмо» во все продающие тексты.

## 5. Сильные стороны — предварительный список (проверяется рынком в заходе 5)

- Единственный контур «репетитор + ученик + AI» в одном продукте: диагностика → программа → материал → проверка → отчёт родителям. Это не «ещё одно приложение для слов».
- Честная бесплатная база: словарь, грамматика, тексты, игры, произношение — без лимитов и без AI-затрат.
- FSRS-повторение связано с играми: ошибка в игре возвращает слово в повторение (обычно этого нет даже у платных аналогов).
- Перевод слова **в контексте предложения**, а не словарная форма.
- Отчёт родителям в один клик — прямое попадание в боль репетитора, работающего с детьми.
- Методичка с исследованиями внутри продукта — редкий ход, повышает воспринимаемую экспертность.
