# Роадмап фич (грилинг, 2026-07) — РЕШЕНИЯ

> Живой документ грилинг-сессии. Здесь фиксируются согласованные решения ДО
> написания финального плана по заходам. Код НЕ трогаем, пока владелец не
> утвердит план. Формат финала: план по заходам + промпт под каждый заход
> (владелец просил /promt-engineer). Workflow — только с дешёвыми моделями и без
> падения качества. Порядок: сначала фичи, ВАЛЮТА — в конце.

## Блок 1 — перевод (дёшево) + кнопка «Разбор предложения» (умно)  ✅ согласовано
- Тап по слову → дешёвый перевод слова (как сейчас, WordSheet, task `word`/light).
- Выделение фразы (зажать+провести) → дешёвый перевод ВСЕГО выделенного в попапе.
  (⚠️ это ИЗМЕНЯЕТ текущее поведение: сейчас drag сразу открывает умный разбор
  через task `analyze` — надо вернуть на дешёвый перевод + кнопку.)
- Кнопка «🔍 Разбор предложения» в попапе появляется при **≥ 5 слов ИЛИ конец
  предложения** (вариант «г»). Жмёшь → умная модель (task `analyze`, standard).
- Разбор = **4 группы**: фразовые глаголы · выражения/идиомы · ключевые слова
  (перевод + «в Мои слова»), и **грамматические структуры** — назвать + объяснить
  + **кнопка «Открыть урок»** (deep-link в нашу грамматику; AI берёт topicId из
  каталога, как в «Программе»; не нашёл — просто объяснение без кнопки). Вариант «б».

## Блок 2A — «Разбор всего текста» (читалка)  ✅ согласовано
- Резка: ~180–200 слов на часть, не разрывая предложения (вариант «б»).
- Цена = (число частей + 1 итог), БЕЗ наценки, показ оценки заранее + подтверждение
  («Разбор всего текста ≈ N AI-действий. Продолжить?»).
- Итог = **5 блоков**: (1) уровень текста + почему; (2) ключевая лексика;
  (3) фразовые глаголы/выражения; (4) грам-структуры с «Открыть урок»;
  (5) «что ты отсюда возьмёшь». Дедуп по всему тексту, addable + «Добавить всё».
  БЕЗ разбора ошибок (текст правильный).
- Кэш: (а) локально у пользователя (localStorage, ключ язык+id/хэш) — первый заход;
  (б) общий кэш готовых текстов в БД (первый платит, остальные бесплатно) — позже.
  Кнопка «Разобрать заново» (платно). Работает и на своих текстах.

## Блок 2B — задание учителя «Письмо» (ученик пишет → AI оценивает)  ✅ согласовано
- **Структура (а):** новый ТИП задания рядом с «Материалами», на общей механике
  назначения/сдачи/проверки (назначил → сдала → AI-разбор → проверка учителем).
- **Режимы:** IELTS и Обычный.
- **Настройки учителя:**
  - IELTS: тип (Task 2 эссе / General Task 1 письмо; Academic Task 1 с графиком —
    НЕ в v1), сам вопрос (учитель пишет или AI генерирует), целевой бэнд (опц.),
    объём по стандарту IELTS (авто).
  - Обычный: тема/задание, ЦЕЛЕВЫЕ СЛОВА (должна употребить), ЦЕЛЕВАЯ ГРАММАТИКА
    (должна применить), уровень + мин. длина.
- **AI-оценка (умная модель, 1 действие за разбор):**
  - IELTS: общий бэнд 0–9 + 4 критерия (Task Response, Coherence & Cohesion,
    Lexical Resource, Grammatical Range & Accuracy).
  - Обычный: уровень + чек-лист целевых слов (✓/✗) + чек-лист целевой грамматики (✓/✗).
  - Оба: ошибки с исправлениями (было→стало, СТРУКТУРИРОВАННЫМ списком — как
    упражнения), сильные стороны, что подтянуть (темы/слова), 1–2 «как усилить».
- **Проверка учителем — ПО-СТРОЧНО** (принять/отклонить каждую правку AI, как в
  «Материалах», переиспользуем ReviewScreen + `teacher_review`) + общий комментарий
  + корректировка бэнда → «проверено».
- **Доработка/итерации:**
  - Текст эссе СОХРАНЯЕТСЯ; последний текст ВСЕГДА виден (для работы над ошибками).
  - История попыток (текст + бэнд + дата) — виден прогресс (5.5 → 6.5).
  - Ученица может САМА править и пересдавать, ПОКА учитель не проверил (каждая
    пересдача = её AI-действие).
  - После проверки — правка открывается по ПЕРЕНАЗНАЧЕНИЮ учителем, с подгруженным
    прошлым текстом (не писать заново).
- База уже есть: режим «Письмо» в Диалоге (task `writing`, `writing_submissions`) —
  переиспользуем промпт/логику проверки письма.

## Отдельный заход — учитель вставляет СВОЙ текст → AI строит задания  ✅ согласовано
- Вариант (а): в «Материалах» переключатель источника текста «Сгенерировать /
  Мой текст». При «Мой текст» AI пропускает генерацию текста и строит ТОЛЬКО
  упражнения (те же типы) по вставленному тексту. Дальше — обычный поток заданий.
- Educational-разбор уровня/лексики (как 2A) сюда НЕ входит — это отдельная кнопка.

## Блок 3 — разбор результатов практики  ✅ согласовано
- После практики рядом с «верно/неверно» — кнопка «Посмотреть результаты» → список
  всех заданий раунда: вопрос, что ввела ученица, верный ответ, ✓/✗.
- Объяснение «почему» — вариант (в) ГИБРИД: список статикой и БЕСПЛАТНО; у каждого
  НЕверного — кнопка «Почему?» → дешёвая модель объясняет это место по запросу.
- Во ВСЕХ режимах, порядок заходов — на усмотрение исполнителя (главное — везде).
- ⚠️ Факт из кода: игры (GameShell/QuizRunner) сейчас НЕ хранят ответы по вопросам,
  только счётчик correct → нужно дозаписывать ответы в каждом режиме.
