# Материалы для звонков репетиторам

> Ф2.13 (PLAN.md), 13.10.2026. Для владельца: всё, что нужно, чтобы звонить
> репетиторам из объявлений, вести контакты законно и доводить согласившихся
> до первой оплаты. Цифры (цены, пробный, места) сверены с кодом на эту дату.
> Поменялись тарифы или правила пробного — править здесь в том же коммите.

## Главное предложение

**Всё расписание и учёт по всем ученикам за 3 900 ₸ в месяц.** «Дешевле
одного урока» — только тем, у кого урок дороже 3 900 ₸; остальным — своя фраза
по цене из объявления (`script.md`, «Перед звонком»). «По всем ученикам» —
правда: карточки учеников без приложения не ограничены ни на одном платном
тарифе, место занимают только ученики в приложении (журнал п.28).

## Что здесь и в каком порядке

| Файл | Когда открывать |
|---|---|
| `legal.md` | один раз прочитать перед первым звонком: что можно, что нельзя, откуда это |
| `contacts-template.xlsx` | шаблон таблицы контактов — каждый день |
| `script.md` | во время звонка |
| `objections.md` | во время звонка, когда возражают |
| `messages.md` | WhatsApp: после звонка, холодное, напоминания, после оплаты |
| `onboarding.md` | созвон-онбординг и созвон через неделю |

Путь одного контакта: объявление → строка в таблице (источник и дата — до
звонка) → звонок (`script.md`) → сообщение А со ссылкой → созвон-онбординг
(`onboarding.md`) → созвон через неделю → оплата → сообщение Е с «Пригласи
коллегу». Каждую субботу — лист «Воронка» таблицы (PLAN.md Ф2.14).

## Таблица контактов

**Ссылка на Google-таблицу:** _ещё нет — владелец загружает шаблон (ниже)._

Как сделать из шаблона Google-таблицу (5 минут, один раз):

1. drive.google.com → «Создать» → «Загрузить файл» →
   `docs/sales/contacts-template.xlsx`.
2. Открыть файл → «Файл» → «Сохранить как Google Таблицу». Дальше работать
   в ней, xlsx на Диске можно удалить.
3. **Проверка, что формулы ожили** — она же проверка импорта. На листе
   «Контакты» в первой строке: телефон `1`, площадка — пусто. Клетки
   площадки, ссылки и даты должны стать **красными**. Впишите площадку
   OLX, любую ссылку и сегодняшнюю дату — красное уйдёт, а на листе
   «Воронка» «Контакты взяты» станет **1 за неделю и 1 всего**. В «Не
   звонить» выберите «да» — строка посереет. Удалите строку. Не
   покраснело, не посчитало или не посерело — скажите Claude, это значит
   импорт что-то потерял.
4. Доступ — только у себя (таблица с номерами людей, `legal.md`, правило 7).
5. Ссылку на таблицу — вставить сюда вместо «ещё нет» (ссылка закрытая,
   по ней откроет только владелец).

Что в таблице: лист «Контакты» — обязательные площадка, ссылка, дата
(закон о персональных данных, ст.7 п.5), выпадающие списки, подсветка:
красное — нет источника, оранжевое — номер уже есть, серое — «не звонить»,
жёлтое — пора сделать следующий шаг. Лист «Воронка» — контакты → дозвоны
→ пробные → онбординги → оплаты за неделю и всего, отказы, главная цифра и
ответы «как ведёте сейчас» (проверка «боль = рутина», PLAN.md Б9). Лист
«Как заполнять» — правила коротко.
