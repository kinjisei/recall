# Восстановление пароля: что настроить в панели Supabase

Код готов и залит, но письмо собирает **Supabase**, а не приложение. Пока
шаблон не заменён, человек получит стандартное английское письмо со ссылкой,
которая ведёт не на наш экран, — и кода в нём не будет вовсе.

Всё ниже делается один раз, руками, в панели проекта `qyvkyyjqqqirmdliddsn`.

---

## 1. Redirect URLs

Прямая ссылка:
https://supabase.com/dashboard/project/qyvkyyjqqqirmdliddsn/auth/url-configuration

Это **белый список адресов, на которые Supabase имеет право вернуть человека**
после письма, а не «постоянная ссылка на сайт». Адрес не из списка отбрасывается,
и человек попадает на Site URL — то есть на главную, без токена: «письмо пришло,
а пароль сменить негде».

Обязательная строка одна:

```
https://recall-pgkz.vercel.app/reset-password
```

**`http://localhost:5173/reset-password` — по желанию и только для разработки.**
`localhost` — это «мой собственный компьютер» для КАЖДОГО, кто откроет такую
ссылку, поэтому чужому человеку она не даст ничего: у него по этому адресу
ничего нашего не запущено. Нужна она ровно в одном случае: посмотреть настоящее
письмо, запустив приложение у себя (`npm run dev`). Проверки её не требуют —
`scripts/smoke-password-reset.mjs` перехватывает запрос в браузере, а ссылки
берёт через `admin.generateLink()`.

Вывод: сейчас достаточно одной прод-строки. Понадобится локальная проверка —
добавите вторую тогда же.

⚠️ Маски (`https://recall-pgkz.vercel.app/**`) Supabase поддерживает, но здесь
они не нужны: чем шире запись, тем больше адресов, куда можно увести человека с
нашим токеном. Точный адрес — точная граница.

## 2. Срок жизни ссылки и кода

Там же, где провайдер Email:
https://supabase.com/dashboard/project/qyvkyyjqqqirmdliddsn/auth/providers
→ раскрыть **Email** → поле **Email OTP Expiration** → поставить `1800` (30 минут).

По умолчанию час. Тридцати минут хватает даже если письмо шло пять минут, а
забытое открытым письмо перестаёт быть ключом к аккаунту до вечера.

## 3. Шаблон письма

Прямая ссылка:
https://supabase.com/dashboard/project/qyvkyyjqqqirmdliddsn/auth/templates
→ вкладка **Reset password**.

Тема письма:

```
Recall — восстановление пароля
```

Тело (заменить целиком):

```html
<div style="font-family:-apple-system,Segoe UI,Roboto,Arial,sans-serif;max-width:520px;margin:0 auto;padding:24px;color:#1a1b2e">
  <p style="font-size:20px;font-weight:600;margin:0 0 16px">Восстановление пароля</p>

  <p style="font-size:15px;line-height:1.6;margin:0 0 20px">
    Кто-то попросил сменить пароль для аккаунта Recall на этом адресе.
    Если это вы — нажмите кнопку. Ссылка живёт 30 минут.
  </p>

  <p style="margin:0 0 24px">
    <a href="{{ if .RedirectTo }}{{ .RedirectTo }}{{ else }}{{ .SiteURL }}/reset-password{{ end }}?token_hash={{ .TokenHash }}&type=recovery"
       style="display:inline-block;background:#5b4fc4;color:#fff;text-decoration:none;padding:14px 28px;border-radius:12px;font-weight:600;font-size:15px">
      Задать новый пароль
    </a>
  </p>

  <p style="font-size:15px;line-height:1.6;margin:0 0 8px">
    Почта на телефоне, а занимаетесь за компьютером? Откройте в приложении
    «Забыли пароль?» → «У меня есть код» и введите:
  </p>
  <p style="font-size:28px;font-weight:700;letter-spacing:4px;margin:0 0 24px">{{ .Token }}</p>

  <p style="font-size:13px;line-height:1.6;color:#6b6c85;margin:0">
    Если вы этого не просили — просто удалите письмо. Пароль останется прежним,
    никаких действий не нужно.
  </p>
</div>
```

Что здесь важно и почему:

- **`{{ .TokenHash }}`, а не `{{ .ConfirmationURL }}`.** Стандартная ссылка ведёт
  на `/auth/v1/verify`, который тратит токен САМ и только потом отправляет
  человека к нам. Ссылки в письмах открывают не только люди: корпоративные
  антивирусы и превью в мессенджерах ходят по ним заранее. С нашим вариантом
  токен тратится в момент, когда человек нажал «Сохранить пароль», — до этого
  ссылку можно открывать сколько угодно раз.
  Это не наша выдумка: ровно этот приём Supabase рекомендует сама, называя
  причину поимённо — Microsoft Defender Safe Links и прочие сканеры почты
  (docs → Auth → Email Templates, раздел про prefetching).
- **`{{ if .RedirectTo }}`** — запасной вариант на случай, когда сброс запущен
  не из приложения (например, из панели): тогда адрес берётся из Site URL.
- **`{{ .Token }}`** — тот самый код. В документации Supabase он описан как
  шестизначный, а наш проект выдаёт **восемь цифр** (проверено на живом
  `generateLink`). Поэтому экран принимает 6–10 цифр: подстраиваться под
  документацию, которая расходится с сервером, — верный способ однажды
  отклонить настоящий код.
- Последний абзац обязателен: человек, который сброс не запрашивал, должен
  понять, что делать ничего не нужно.

## 4. Проверить после настройки

1. На проде нажать «Забыли пароль?», ввести свой адрес.
2. В письме должны быть **и кнопка, и восьмизначный код**.
3. Кнопка открывает `https://recall-pgkz.vercel.app/reset-password` — без
   полей адреса и кода, сразу поле нового пароля.
4. Сменить пароль. Приложение на других устройствах должно попросить войти
   заново — так и задумано.

## Пределы, о которых стоит знать

- **Brevo, бесплатный тариф — 300 писем в сутки.** Это про доставку.
- **Свой лимит Supabase** — Authentication → Rate Limits → «Rate limit for
  sending emails», по умолчанию 30 писем в час на весь проект. Он действует
  ПОВЕРХ лимита Brevo и делится между подтверждениями регистрации и
  восстановлением пароля. Тридцати в час хватает; знать, где крутится, полезно.
- **Человек без доступа к почте** восстановиться не может — это осознанное
  решение, а не недоделка. На экране есть строчка «Напишите нам», адрес
  меняется руками в панели: Authentication → Users → нужный человек → Email.
  Убедитесь сперва, что это тот человек: смена адреса = передача аккаунта.

## Чего в коде нет намеренно

- Кнопки «сбросить пароль ученику» у преподавателя. Аккаунт ученика нельзя
  забирать через учителя, даже с добрыми намерениями.
- Такой же кнопки у владельца в `/admin`. Помощь идёт через смену адреса
  вручную — медленнее, зато не создаёт кнопку «забрать любой аккаунт».
