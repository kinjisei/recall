# docs/legal — юридическое по закону РК о персональных данных

Появилась по итогам Ф2.22 (юридический ресёрч, 02–03.11.2026). Сам отчёт с
цитатами законов — приватная страница-Artifact (ссылка — в `docs/PLAN.md`,
Ф2.22). Здесь — внутренние документы оператора и черновики, которые
утверждает или отправляет владелец.

| Файл | Что это | Статус |
|---|---|---|
| `pd-list.md` | Перечень персональных данных по форме приказа № 199/НҚ | черновик, утверждает владелец |
| `pd-procedure.md` | Внутренний порядок сбора, обработки и защиты ПД; назначение ответственного; доступы; сроки; обращения людей | черновик, утверждает владелец |
| `incident-plan.md` | Что делать при утечке: шаги, срок 1 рабочий день, шаблон уведомления министерству | черновик, утверждает владелец |
| `eotinish-request.md` | Обращение в министерство о хранении за рубежом и категории оператора | отправляет владелец |

Публичные документы сайта (`/terms`, `/privacy`) живут в
`src/features/legal/LegalPage.tsx` и меняются отдельным пунктом плана после
решений владельца по Ф2.22.

Правила:
- **Личные данные сюда не кладём** (ФИО и ИИН владельца — заглушками, пока
  репозиторий публичный). Подписанные экземпляры хранит владелец у себя.
- Меняешь, какие данные берёт приложение, — правь `pd-list.md` и
  `pd-procedure.md` в том же коммите.
- Законы цитируются по https://old.adilet.zan.kz с датой редакции.
