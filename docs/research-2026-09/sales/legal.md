# Законность холодного обзвона (Sonnet, 25.09.2026, ~110k токенов) — сырой отчёт

Ключевое:
- Закон РК «О рекламе» (508-II): статьи про обязательное согласие абонента на
  рекламу звонком/SMS/мессенджером НЕТ (в отличие от РФ). Ст.10 п.3 — только про
  платные справочные сервисы. Источник: kodeksy-kz.com (зеркало), adilet не отдал
  текст. Уверенность высокая по отсутствию статьи, средняя по формулировкам.
- КоАП ст.455 — состава «реклама без согласия абонента» нет (зеркало, средняя).
- Закон «О персональных данных» (94-V): ст.7 п.5 — «Допускается повторный сбор,
  обработка и распространение третьими лицами персональных данных, опубликованных
  на основании пунктов 3 и 4 настоящей статьи, при условии наличия ссылки на
  источник информации». → номера из объявлений собирать можно, но ХРАНИТЬ
  ИСТОЧНИК (площадка + ссылка на объявление + дата). Источник: zakon.uchet.kz
  (зеркало полного текста). Уверенность высокая по цитатам.
- Kaspi Объявления, соглашение АО «Колеса» п.4.1(1): запрещено использовать
  номер другого пользователя «для целей прямой рекламной рассылки…» —
  подтверждено прямым фетчем. Риск гражданско-правовой (бан/претензия площадки),
  не административный.
- OLX.kz: дословное правило не получено (SSO) — не подтверждено.
- WhatsApp: по вторичным источникам политика требует согласия на переписку;
  массовые шаблонные сообщения незнакомым → ограничение/бан номера.
  Первоисточник whatsapp.com не получен (404).

Итог агента: можно — собирать номера с источником, звонить/писать вручную,
представиться, назвать источник, дать отказ; серая зона — правила площадок;
нельзя — массовые одинаковые WhatsApp-рассылки, сбор без пометки источника.
Приёмы: колонка «источник», ручной контакт с личного номера, не повторять после
отказа, звонок/Telegram основным каналом, WhatsApp вторичным, без ботов.

Не выяснено: правила OLX дословно; ст.455 с adilet; официальная политика WhatsApp;
правила Market.kz и 2GIS.

⚠️ Юр-выводы: при использовании в плане — перепроверить ст.7 п.5 по adilet
(первоисточник), это основание всей схемы сбора номеров.
