## Уведомления и мессенджеры

**Кнопки «поделиться»** — 0 ₸, без сервера. `wa.me/<номер>?text=` (текст в поле,
отправка вручную — faq.whatsapp.com/5913398998672934); `t.me/share/url?url=&text=`
(core.telegram.org/widgets/share); Web Share API — Android и iOS Safari, нужен
жест пользователя (developer.mozilla.org/.../Navigator/share). Автоматически не
уходит — только по нажатию человека.

**Telegram-бот** — 0 ₸. Бот не может написать первым: «Bots can't start
conversations with users» (core.telegram.org/bots/faq). Привязка аккаунта —
deep link `t.me/<бот>?start=<параметр>` до 64 символов (core.telegram.org/api/links).
Лимиты: ≤1 сообщ./сек в чат, ≤30/сек всего (Bots FAQ). От владельца — бот у
@BotFather; требований документов в доках нет (прямой цитаты «не нужны» нет).

**WhatsApp Business Platform (Cloud API)** — оплата за сообщение с 01.07.2025;
utility $0,004–0,0456, marketing $0,025–0,1365 за сообщение по рынкам мира;
ответы в 24-часовом окне бесплатны (developers.facebook.com/documentation/
business-messaging/whatsapp/pricing). Точная ставка для Казахстана — **не
проверено** (rate card за логином); с **01.10.2026 Казахстан выделяется в
отдельный прайс с повышенными utility/authentication** (там же). Наш объём:
1 500 × $0,004–0,0456 = $6–68 ≈ **2 650–30 000 ₸/мес** + посредник (Twilio
$0,005/сообщ. ≈ +3 300 ₸, twilio.com/en-us/whatsapp/pricing; 360dialog от €49/мес,
360dialog.com/pricing). Новый номер — **250 получателей/24 ч**; рост лимита —
через верификацию бизнеса или 2 000 качественных сообщений за 30 дней
(developers.facebook.com/.../messaging-limits). Верификация требует документов
о **зарегистрированной** деятельности — без ИП не подтверждено возможной
(docs.360dialog.com/docs/resources/meta-business-verification). Номер — отдельный,
не используемый в приложении WhatsApp. Шаблоны — на модерации Meta.

**Push PWA (Web Push)** — 0 ₸ (своя отправка по VAPID или OneSignal Free:
web push без лимита подписчиков, onesignal.com/pricing). iPhone — **с iOS/iPadOS
16.4, только после «Добавить на экран Домой»** и разрешения по нажатию кнопки
(webkit.org/blog/13878). Надёжность, если приложение давно не открывали, —
официальной цифры нет.

**Почта** — встроенная Supabase: **2 письма/час**, только для тестов
(supabase.com/docs/guides/auth/rate-limits). Resend Free — 3 000/мес, 100/день,
**без своего домена — только на свой адрес** (resend.com/docs/knowledge-base/
what-is-resend-pricing). Brevo Free — 300/день, аутентификация домена
обязательна (help.brevo.com/hc/en-us/articles/14925263522578). Postmark Free —
100/мес (postmarkapp.com/support/article/1002). **Без домена рассылка ученикам
не работает** (домен отложен, журнал п.20).

**Планировщик** (чтобы сообщение ушло без открытого приложения):
- Vercel Cron Hobby — **не чаще раза в сутки, точность «в пределах часа»**; Pro —
  раз в минуту (vercel.com/docs/cron-jobs/usage-and-pricing).
- Supabase `pg_cron` + `pg_net` — **есть на бесплатном тарифе**, шаг от секунды,
  ≤8 одновременных задач, ≤10 мин каждая (supabase.com/docs/guides/cron).
- Supabase Edge Functions — 500 000 вызовов/мес бесплатно
  (supabase.com/docs/guides/functions/pricing).
- GitHub Actions `schedule` — не чаще раза в 5 мин, возможны задержки, 2 000
  минут/мес на приватный репозиторий (docs.github.com, events-that-trigger-workflows).

## Онлайн-уроки

**А. Внешняя ссылка.** Zoom Basic — **40 мин на любую встречу**
(support.zoom.com, KB0067966); облачная запись — только платно, локальная — и
бесплатно (KB0059856). Google Meet бесплатно — **1:1 до 24 ч, 3+ участника —
60 мин** (support.google.com/meet/answer/13396001); запись на бесплатном
аккаунте — **не проверено** официально. Telegram — групповые видеозвонки, видео
у первых 30 (telegram.org/blog/group-video-calls, 2021). Автосоздание ссылок —
Zoom OAuth-приложение + Security Review (developers.zoom.us/docs/integrations/
create); Google Calendar API — верификация чувствительного scope, нужен домен и
политика (developers.google.com/.../sensitive-scope-verification) — риск без домена.

**Б. Видео внутри сайта (готовый сервис).**
- 8x8 JaaS: бесплатно **25 MAU**; Basic $99/мес — 300 MAU (≈43 700 ₸); запись
  $0,01/мин (cpaas.8x8.com/.../jitsi-as-a-service-pricing).
- Daily: 10 000 участнико-минут бесплатно, далее $0,004/мин; запись
  $0,01349/мин (daily.co/pricing/video-sdk) → ≈258 000 ₸/мес без записи.
- Whereby Embedded: Build $9,99 + $0,004/мин, запись $0,01/мин
  (whereby.com/information/embedded/pricing) → ≈276 600 ₸/мес без записи.
- LiveKit Cloud: Build — 5 000 мин + 50 ГБ бесплатно, далее $0,0005/мин и
  $0,12/ГБ; запись $0,02/мин видео, $0,005/мин аудио (livekit.com/pricing) →
  ≈33 400 ₸/мес без учёта трафика (трафик — оценка, не официальная цифра).
- Запись 1 300 ч (78 000 мин) у провайдера: +345 000 ₸ (JaaS) … +465 000 ₸ (Daily).

**В. Своя видеосвязь (WebRTC).** Hetzner CPX22 €19,49/мес (≈9 800 ₸), CPX32
€35,49 (≈17 900 ₸) (docs.hetzner.com/.../price-adjustment, с 15.06.2026) + TURN и
медиасервер своими силами; недели работы и постоянная эксплуатация.

**Согласие на запись.** Закон РК «О персональных данных» (94-V): ст.1 —
персональные данные = сведения, по которым можно определить человека; ст.7 —
сбор с согласия субъекта или законного представителя. Текст взят с зеркала
(adilet не отдаётся автоматически). Что запись урока — персональные данные,
это толкование, а не прямая цитата. Практически: экран согласия перед записью,
для учеников до 18 — согласие родителя.

**AI-конспект по записи.** Groq Whisper: large-v3 $0,111/ч, turbo $0,04/ч
(console.groq.com/docs/model/whisper-large-v3[-turbo]); бесплатно — 2 000
запросов/день, **28 800 аудио-секунд/день (8 ч)**, файл ≤25 МБ
(console.groq.com/docs/rate-limits). 1 300 ч/мес бесплатно **не помещается**;
платно: turbo $52 ≈ **23 000 ₸/мес**, large-v3 $144 ≈ 63 800 ₸. Захватить звук
урока Recall может только если звонок внутри сайта (Б/В) или учитель загрузит
запись сам.
