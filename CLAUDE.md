## Что это

**Recall** — PWA для изучения английского и испанского: переключатель EN/ES в
шапке, язык в localStorage `recall.lang`. Продаётся частным репетиторам
Казахстана; оплата пока ручная (перевод на Kaspi → «Оплата отправлена» →
владелец подтверждает в `/admin`, `src/domains/billing/CLAUDE.md`). Начинался
как личный проект владельца и его девушки — отсюда часть решений в истории.

- **Ученик сам по себе** — слова (FSRS), чтение с разбором по тапу, речь,
  диалог с AI, грамматика, письменные работы с проверкой по критериям IELTS.
  Контент: английский — авторский, испанский — из приложения Loro
  (`src/data/CLAUDE.md`).
- **Студия репетитора** — расписание уроков, ученики, домашка на неделю,
  материалы и задания, проверка работ, диагностика, программа, AI-квесты,
  отчёт родителям.

## Язык общения

Отвечай **по-русски**. Владелец — новичок в программировании, работает в своём
VS Code, где у Claude есть файлы и терминал: фичи собираются прямо в проекте и
тут же проверяются скриптами.

## Слои и папки

```
src/app/         каркас: вход, все адреса и доступ (routes.ts), меню, рамка
src/features/    экраны по разделам
src/domains/     предметные правила без интерфейса: index · api · model · CLAUDE.md
src/shared/      нижний этаж без предметной логики: ui (токены, компоненты),
                 lib (утилиты), api (клиент базы, клиент AI, ошибки)
src/lib/         старая логика вне экранов → переезжает в domains/ (PLAN.md Ф3)
src/components/  старые общие куски с предметной логикой → в разделы
src/context/ · src/types/ · src/data/   вход и язык · общие типы · контент
api/ · supabase/ · scripts/   сервер · база · проверки и генераторы
```

Правила (архитектура §2, держит сторож границ): нижний этаж не знает о
верхних; `shared/` импортирует только `shared/`; в чужой раздел — только через
его `index.ts`; в базу — только из `domains/*/api.ts` (до переезда — `lib/` и
`context/`). Новый код — сразу так: экран в `features/<раздел>`, правила и
база в `domains/<имя>`.

**Описания модулей** — по шаблону (`npm run gen:docs` пишет блок generated).
Модуль из `lib/` или `components/` с механикой раздела несёт в начале строку
`// Описание: src/features/<раздел>/CLAUDE.md`. Изменил код — обнови описание
в том же коммите или напиши «описание не меняется, потому что …»; у раздела
без своего описания это — этот файл.

## Безопасность — три правила, нарушение которых уже стоило дыр

1. **Всё, что можно подделать, считает сервер.** Балл за задание, вердикт
   перепроверки слов, прогресс квеста — security-definer RPC. Прямая запись в
   `material_assignments`, `word_checks`, `activity_log` и т.п. отозвана.
2. **RLS не прячет колонки.** У `profiles` **колоночные гранты**: новая
   колонка без явного `grant select`/`grant update` будет невидима клиенту и
   не сохранится — молча, без ошибки. Секреты (`plan`, `invite_code`,
   `is_admin`) через REST не читаются, только через `get_my_plan()`.
3. **Сервер ходит в базу под токеном пользователя**, своего ключа у него нет.
   Значит любая RPC, которую зовёт сервер, доступна и из браузера. Отсюда
   `refund_token`: возврат энергии возможен только по неугадываемому номеру,
   который сервер клиенту не отдаёт.

Права на новые функции базы — два пояса (`supabase/CLAUDE.md`). **Осознанные
остатки** (PLAN.md Ф2.15): расписание повторений (`review_states`) и счётчики
занятий пишет клиент — упорный ученик накрутит себе диагностику и автозачёт
домашки; ответы упражнений доходят до браузера (балл — сервер, подсмотреть можно).

## Как запустить и проверить

```
npm run dev          # http://localhost:5173 — ЖИВАЯ база: AI списывает ⚡ по-настоящему
npm run dev:test     # http://localhost:5174 — тестовая база (для смоуков)
npm run build        # tsc -b + сборка — обязательно после правок
npm run check        # все сторожа — обязательно после правок
npm test             # все чистые тесты scripts/test-*.mjs
npm run gen:docs     # пересобрать блоки generated в описаниях модулей
npm run db:migrate   # миграции → тестовая база (+ права анонима, типы)
```

Остальные проверки — в описании модуля; смоуки — `scripts/CLAUDE.md`.
**Сторожа** (`scripts/checks/README.md`): линтер, границы, токены, размер
(файл ≤ 400 строк, компонент ≤ 250), план, блоки описаний, описания — перед
коммитом, в `npm run check` и в CI. Старые нарушения — «к исправлению», новые
не проходят, список не расширяется; **большие файлы не растут** (решение
владельца 27.09.2026). `--no-verify` — только с согласия владельца.

## Правила работы

- **Нашёл ошибку — почини весь её класс:** не одно место, а все соседние того
  же вида; общее решение выноси, в отчёте называй, сколько нашлось. Пока правку
  откладывали, класс успевал вырасти.
- **Правь на месте, а не дописывай в конец** (код, документы, скрипты): в
  файле — ТЕКУЩЕЕ состояние, история — в `git log`. `docs/schema.sql` так дорос
  до 4885 строк, треть — мёртвые версии функций. Исключение — применённые
  миграции (`supabase/CLAUDE.md`).
- **Проверка должна уметь краснеть.** Тест без утверждений — не тест: был
  вечно зелёный `test-fsrs-graduation.mjs` с нулём проверок и смоуки,
  сравнивавшие то, что не менялось.
- **Общие сигнатуры не ломать** (`lib/cards`, `fsrs`, `speech`… —
  `src/lib/CLAUDE.md`), расширять можно; типы — из `src/types`.
- **Прод и живую базу не трогать:** проверки — на тестовой базе; миграции на
  живую катит владелец сам (порядок — `supabase/CLAUDE.md`); `--prod` у
  скриптов — только с его согласия.
- **Коммит без пуша; пуш — не чаще раза в 2–3 часа**, внеочередной — только с
  «да» владельца: у Recall живые ученики.
- Перед `git add -A` смотреть, что попадает: бывают параллельные сессии.

## Уроки, которые дорого достались

- **Квоты Google помодельные.** Цепочка моделей складывает квоты; ставить
  дефицитную модель первой — выжечь её всем.
- **Supabase хранит email в нижнем регистре**, кириллица в локальной части
  адреса молча отклоняется (аккаунт не создаётся).
- **SQL `translate()` УДАЛЯЕТ** символы, для которых не нашлось пары в строке
  замены. Длины списков обязаны совпадать.
- **Сверка ответа продублирована:** `lib/text.ts` и `norm_typed` в SQL.
  Меняешь в одном — меняй в другом, иначе клиент покажет «верно», а балл не
  начислится (`check-answermatches-sql.mjs`, живая база, вне CI).
- **Нормализация приводит начертание символа, но не удаляет символ.** Кривой
  апостроф с телефона — вина клавиатуры; пропущенный апостроф — ошибка ученика.
- **Без связи экран говорит о связи, а не «0» и не «пусто»** (PLAN.md Ф1.13).
  Сбой, выданный за пустоту, хуже любой ошибки: «серия 0», «квестов нет»,
  учителю — «включи режим преподавателя», после ночи без сети — форма
  регистрации. Загрузка при сбое бросает, экран — `useAsyncData`/`settleAll`
  и `LoadError` с «Повторить» (`src/shared/CLAUDE.md`). Клиент Supabase на
  сетевой ошибке сам повторяет чтение 1 + 2 + 4 с, а `auth.getUser()` ходит в
  сеть — кто вошёл, спрашивай у сессии (`currentUserId`).
- **Набранное переживает перезагрузку** (PLAN.md Ф1.14): новая версия
  включается сразу и перезагружает страницу. Поле с длинным текстом и форма с
  AI-результатом — через `useDraft`/`useDraftForm` (`src/shared/CLAUDE.md`);
  «Диалог», квесты и «Свой текст» — уже так.
