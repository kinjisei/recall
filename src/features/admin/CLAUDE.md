# admin — админка владельца (`/admin`)

## Простыми словами

Рабочий экран владельца. Сверху то, с чем он работает чаще всего:

- **«Оплаты»** — заявки «Оплата отправлена», которые ждут сверки с Kaspi:
  «Подтвердить» (тариф включается сразу, человеку приходит «Оплата
  получена») или «Не пришло». Ниже — последние подтверждённые оплаты.
- **Поиск человека** по email или личному коду из сообщения к переводу. У
  найденного — «Подтвердить оплату» (перевёл, а кнопку не нажал) и ручная
  правка тарифа без оплаты: подарок, исправление, выключить.

Дальше — тема на этом устройстве, воронка (визиты → регистрации → … →
оплаты, по источникам), расход AI, отзывы и ошибки у пользователей.

Видит экран только владелец (`app/routes.ts`, `role: 'admin'`), но настоящую
защиту держит база: каждая `admin_*` и `confirm_payment` сами проверяют
`is_admin`.

| Файл | Что там |
|---|---|
| `AdminPage.tsx` | страница: порядок блоков, воронка, отзывы, ошибки с прода |
| `payments/Payments.tsx`, `payments/ConfirmPayment.tsx` | оплаты: заявки, форма подтверждения с подсказкой «Станет: … до …», последние оплаты (правила — `domains/billing/CLAUDE.md`) |
| `UserSearch.tsx` | поиск по email или коду, «Подтвердить оплату», ручная правка тарифа |
| `AiUsage.tsx` | расход AI (`domains/ai/CLAUDE.md`) |
| `DeviceTheme.tsx` | тема на этом устройстве (`shared/ui/CLAUDE.md`) |
| `src/lib/admin.ts` | поиск, ручная правка тарифа, ошибки и отзывы — RPC `admin_*` |

## Правила, которые нельзя нарушить

- **Оплата — только «Подтвердить»**, то есть `confirm_payment`. Ручная правка
  (`admin_set_plan`) — не оплата: ни строки в журнале оплат, ни события в
  воронке. Иначе выручка и воронка врут.
- **Воронка считает людей, а не события, источник — первый по времени.**
  Событие оплаты пишет база от имени плательщика (`domains/billing/CLAUDE.md`).
- **Блок не роняет админку.** Сбой одного блока — строка с причиной в нём,
  остальные работают; «Повторить» пока только у «Оплат» (остальные блоки —
  PLAN.md Ф2.24).
- **Подтвердили оплату из поиска — блок «Оплаты» перечитывается**: общий
  счётчик в `AdminPage` (`paidVersion`).

## Как проверить

- `node scripts/smoke-billing.mjs` — заявка, подтверждение, последние оплаты,
  админка на 390 и 1280 (нужен `npm run dev:test`).
- `node scripts/smoke-shell.mjs` — админку видит только владелец.
- `node scripts/smoke-ai-usage.mjs`, `node scripts/smoke-feedback.mjs` —
  блоки расхода AI и отзывов.

## Решения и почему

- **Поиск и ручная правка — в `UserSearch.tsx`**: страница была больше
  предела размера (487 строк), а в неё пришли оплаты (PLAN.md Ф2.1).
- **Оплаты — первым блоком**: это ежедневная работа владельца, а воронка и
  ошибки — раз в неделю.
