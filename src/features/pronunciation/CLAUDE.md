# pronunciation — тренажёр речи: послушай, повтори, оценка

## Простыми словами

«Речь» (`/pronunciation`, вход из «Практики») — шэдоуинг: телефон читает
фразу вслух (можно медленно), ученик повторяет в микрофон, сервер распознаёт
запись (Groq Whisper, `/api/transcribe`), а экран показывает, какие слова
совпали, и процент. Распознавание ⚡ не стоит.

Первыми идут **свои слова ученика** — само слово и пример к нему, по свежести
повторения, для обоих языков; на экране они помечены, это другое дело, чем
встроенные фразы. Проговорить вслух — значит запомнить лучше, чем прочитать
глазами, поэтому так закрывается и пункт домашки «Проговорить вслух»
(`features/homework/CLAUDE.md`).

| Файл | Что там |
|---|---|
| `PronunciationPage.tsx` | очередь фраз, запись, оценка |
| `src/lib/speech.ts` | озвучка (Web Speech API) и оценка `scorePronunciation` |
| `src/lib/transcribe.ts` | запись и отправка на распознавание |

## Правила, которые нельзя нарушить

- **Свои слова — первыми, и слова тоже, не только фразы.** Раньше фильтр
  `/\s/.test(p)` выбрасывал всё без пробела, то есть ровно слова, и работал
  только для английского: испанский ученик тренировал исключительно
  встроенные фразы.

## Как проверить

- **Отдельной проверки экрана нет.** `node scripts/smoke-features.mjs` видит
  только раздел «Речь» в «Практике», `smoke-homework` — зачёт речи в домашке.
  Свои слова первыми и оценку проверять руками на `npm run dev:test`.
- Порядок слов оценка пока не видит — поправка запланирована в PLAN.md Ф3.11.
