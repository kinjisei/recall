# features/schedule — экран «Расписание» учителя (/schedule)

## Простыми словами

Расписание репетитора по макетам t2–t5, t7-4, t9-3, d1, d2 (PLAN.md Ф2.7).
Вид «День»: полоска недели с точками, лента часов, линия «сейчас», у
ближайшего урока — «через 50 мин». Вид «Неделя»: колонками по часам (на
компьютере по умолчанию, журнал п.46) или списком по дням (на телефоне по
умолчанию). Урок показывает состояние словом: «Автосписание», «Поздняя отмена»
(штриховка), «Отменён» (пунктир), «Перенесён», «Пробный», «Не отмечен».

Шторки: «Новый урок» (тип, ученик или группа — можно завести нового прямо
здесь, дата — календарь месяца, время — колёса, длительность, повтор по
неделям, ссылка), урок (войти, остаток, кто был — «На уроке / Не было» и
«Списать / Не списывать», действия), «Перенести», «Изменить» (та же шторка,
что «Новый урок»), «Отменить» («не списывать / поздняя отмена», «только этот /
этот и все следующие»), «Сообщи ученику» (WhatsApp на номер из карточки,
Telegram, «Текст»). После пробного урока — «<имя> остаётся заниматься?»:
«Да» — «занимается» и сразу «+4 / +8 / +12», «Нет» — архив с «Вернуть».

Новый репетитор видит «Пока нет уроков»: «Добавить первого ученика» открывает
шторку карточки, после неё — сразу «Новый урок» с этим учеником. До меню
учителя (Ф2.10) сюда ведёт вкладка «Расписание» в студии (`StudioTabs`).

## Правила, которые нельзя нарушить

- **Решает база, экран подсказывает.** Почему «Создать» нельзя
  (`draftProblem`), какие отметки можно (`allowedOutcomes`), можно ли
  перенести (`canEdit`) — копии правил базы; ошибку базы показываем словами
  (`dbError`). Своих правил сверх базы экран не заводит.
- **Время — по Алматы**, не по поясу телефона: только функции
  `domains/schedule` (там сторож против местного времени).
- **Без тарифа после пробного — только просмотр** (журнал п.41; макет t9-3):
  плашку «Тариф закончился» ставит каркас (`showsAccessBanner` — и на
  /schedule), под ней строка «расписание только для просмотра», действия
  выключены с «продли тариф · Продлить», «Новый урок» — тост «Продлить».
  Вопрос после пробного без тарифа не задаём — ответ всё равно не записать.
- **Сбой — не пустота** (Ф1.13): уроки не загрузились — `LoadError` с
  «Повторить», а не «Пока нет уроков»; ответ для другой недели не
  показывается под новыми датами.
- **Адрес = «где я»**: листание и смена вида — заменой записи (иначе «назад»
  прошёл бы по каждому дню), открытый урок — новой записью («назад» и свайп
  закрывают шторку).
- **«Сообщи ученику» после переноса, отмены и «Напомнить»** (журнал п.38,
  42, 68): с Ф2.9 Recall сам пишет ученикам в приложении
  (`APP_TELLS_STUDENTS = true`), поэтому шторка — только для тех, до кого он
  не достаёт: без приложения и в приложении с выключенными уведомлениями
  («уведомления в Recall выключены, напиши сам»; `get_students_push` —
  только «включены ли»). Все достаются сами — шторки нет.
- **Перед «этот и все следующие» — сколько отдельно перенесённых уроков
  впереди перестроится** (журнал п.65, 3; `rebuildCount`). Отмена серии
  удаляет уроки после — «Вернуть» у неё нет, это сказано до нажатия.
- **Пауза и архив — сколько уроков уйдёт и что разовые не вернутся**
  (журнал п.65, 1; `features/students` — `useLeavingLessons`): из меню
  карточки и из «Нет» после пробного.
- **Тач-цели ≥ 44** (`ux-audit-schedule`): в мини-сетке недели на телефоне
  урок не кнопка — нажимается колонка дня целиком (подпись под сеткой, t2-2).

## Как проверить

- `node scripts/smoke-schedule.mjs [--shots <папка>]` (нужен `npm run dev:test`)
  — весь путь из «Готово, когда»: пустое → первый ученик → первый урок; серии
  у трёх карточек, включая группу; пробный → «остаётся» → «+8»; перенос одного
  (серия не рвётся, «Сообщи ученику» — WhatsApp на номер); «этот и все
  следующие» — предупреждение; отмена с поздним списанием и «Вернуть»;
  неделя целиком; пауза — предупреждение и уроки ушли; только просмотр; 1280 —
  неделя колонками и панель справа. Краснеет, если отмена не списывает или
  перенос не меняет время (проверено 04.10.2026).
- `node scripts/ux-audit-schedule.mjs [--theme light]` — контраст и тач-цели
  экрана и всех шторок на 390 и 1280; выход 1, если есть замечания.
- `node scripts/test-schedule-screen.mjs` — правила экрана без базы.
- `node scripts/smoke-lesson-balance.mjs [--shots <папка>]` — учёт уроков:
  оплата с датой, 7 списаний → «1» в строке и одно уведомление → лента →
  «Напомнить» сразу открыт, текст t7-3, WhatsApp на номер; 1280 —
  «Требуют внимания»; история и исправление задним числом; ученику — только
  сообщение учителя по нажатию.

## Решения и почему

- **Тело шторок — общий `SHEET_BODY`** (`shared/ui/Sheet.tsx`): своя копия
  классов в девяти шторках сжимала кнопки при длинном содержимом — «Готово» в
  «Напомнить об уроке» при трёх учениках было 24 px (Ф2.9, UX-аудит).
- **Форма урока после «Добавить первого ученика» получает карточку сразу**
  (`seed`, `provisionalCard`): список ещё перечитывается, и полсекунды форма
  показывала «Новый ученик» вместо только что добавленного.

- **Дата и время — свои, как в макете** (календарь месяца, колёса; решение
  владельца 04.10.2026), а не системные окна телефона: `shared/ui`
  `DatePicker`, `TimeWheel`.
- **«Изменить» — та же шторка, что «Новый урок»** (решение владельца
  04.10.2026): без неё ученика в группу не добавить, только отменить серию и
  создать заново.
- **«Карточки группы» из макета нет**: группа — это серия с названием, своей
  карточки у неё нет; в шторке группы участники ведут в свои карточки.
- **Имена без падежей** («Аружан Сейтова остаётся заниматься?», «Тимур Ким —
  без приложения»): склонять казахские и русские имена правилом нельзя, а
  ошибка в имени заметнее простого оборота.
- **«Отменить урок» — `danger-outline`, а не сплошной красный** макета t5-2:
  белое на `danger` в тёмной теме — 4,4:1, ниже нормы для текста; сплошной
  вернётся с токенами редизайна (Ф2.17).
- **Панель справа на компьютере пока затемняет неделю**: правило d0
  «панель сдвигает содержимое без затемнения» — правка общего `Sheet` в Ф2.17.
- **День на компьютере — колонкой 640**, неделя — шириной страницы: ленте
  одного дня на 1100 px нечего показать сбоку.
- **После «Да» на пробном — сразу «Отметить оплату»** (журнал п.30) — та же
  шторка, что в карточке, с «Позже».
- **Учёт уроков (Ф2.8) живёт здесь, а карточку собирает студия**:
  `features/teacher` вставляет `CardLessons` и `AttentionPanel` через дверь
  раздела. История — шторкой (на компьютере — панелью справа), а не
  отдельным экраном, как в t7-2: из неё одно движение назад к карточке.
- **«Напомнить» об оплате ученик получает только по нажатию учителя**
  (`send_card_message`; журнал п.29) — правила «об оплате ученику» нет.
  Текст правится и переживает перезагрузку (`useDraft`, Ф1.14). «Напомню
  лично» просто закрывает шторку.
