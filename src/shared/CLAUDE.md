# shared — общие кирпичи без предметной логики

## Простыми словами

Нижний этаж приложения. Здесь то, что нужно всем экранам и ничего не знает
ни про слова, ни про учеников, ни про домашку: как безопасно сохранить
настройку в браузере, как держать «где я» в адресе, как плавно сменить экран,
как загрузить данные экрана и честно показать ошибку, как написать «5 слов»,
а не «5 слова». И два «провода» наружу: к базе (Supabase) и к нашему серверу
AI — с человеческими текстами ошибок вместо технических.

Раньше всё это лежало вперемешку с логикой разделов в `src/lib`. Теперь у
кирпичей свой этаж, и сторож следит, чтобы он оставался нижним.

| Папка | Что там |
|---|---|
| `api/` | `supabase` — единственный клиент базы; `database.types` — типы базы (генерируются, руками не правятся); `errors` — ошибка базы → текст для человека (`dbError`, `describeDbError`) и `AppError` с кодом причины; `ai` — клиент `/api/gemini` (`chat`, `chatStream`, `onAiRequest`); `aiTypes` — протокол AI (`AiTask`, `ChatTurn`), общий с сервером |
| `ui/` | дизайн-система: общие компоненты без предметной логики — `Button`, `Card`, `Sheet`, `Picker`, `TabPicker`, `RowCard`, `Reveal`, `HowItWorks`, `Loading`/`RowsSkeleton`, `LoadError`, `Thinking`, `BackButton`/`BackHeader`, `SmartBack`, `AppLink`, `Brand`, `Confetti`, `icons` |
| `lib/` | утилиты: `morph` (плитка «вырастает» в экран), `storage` (localStorage без падений), `useUrlState` (адрес = «где я»), `viewTransition` (плавная смена экрана), `useAsyncData` (загрузка: «пусто» ≠ «ошибка»), `plural` (числительные), `contacts` (адрес поддержки), `focusMode` (режим раунда: экран включает, каркас прячет шапку и навигацию), `routePreload` (прогрев экранов для `AppLink`: реестр регистрирует каркас), `shellInsets` (сколько места занимает каркас: меню слева, навигация снизу — для закреплённых элементов экранов), `useMediaQuery` (`useIsDesktop` — компьютер от 1024 px) |

## Правила, которые нельзя нарушить

- **`shared/` импортирует только `shared/` и пакеты.** Ни `lib/`, ни
  `components/`, ни разделов, ни `types/`. Держит сторож границ (правило
  `shared-only-shared`, `scripts/checks/boundaries.config.cjs`). Понадобилось
  что-то сверху — значит, либо это не кирпич, либо зависимость надо развернуть
  (подписка, параметр), а не протащить импорт.
- **Клиент базы — один** (`api/supabase`). Импортировать его могут только
  слой данных (`domains/*/api.ts`, `domains/profile`) и, до переезда, старые
  `lib/` и `context/` — правило `db-outside-data-layer`. Экран в базу не ходит.
- **Типы базы генерируются**: после каждой миграции
  `node scripts/check-types-drift.mjs --write` и коммит вместе с миграцией.
- **`api/aiTypes.ts` без импортов.** Его читает сервер (`api/*`): любой импорт
  отсюда потянул бы в сборку функций Vercel клиентский код (клиент базы
  читает `import.meta.env`, которого там нет). Проверка —
  `node scripts/check-api-vercel.mjs`.
- **Клиент AI не зовёт аналитику сам.** Событие воронки `ai_first` подписывает
  каркас (`onAiRequest` в `main.tsx`) до первого рендера: аналитика —
  предметная область и лежит выше. Модель клиент не выбирает — только задачу
  (`AiTask`), остальное решает сервер (`api/_tasks.ts`).
- **Ошибка базы — через `dbError`**: человеку — что случилось и что делать,
  подробность — в консоль. Наш русский текст из RPC не заменяется общим.
- **Договор с каркасом — здесь, выполняет каркас.** `focusMode`,
  `routePreload` и `shellInsets` — не утилиты, а «розетки»: экран и `AppLink`
  зовут их, а `app/` подключает (контекст режима раунда и геометрию даёт
  `Layout`, реестр экранов регистрирует `app/routeChunks`). Так экран не
  импортирует каркас.
- **Закреплённый (`fixed`) элемент экрана берёт отступы из `shellInsets`**, а
  не заводит свои «88 px под навигацию»: на компьютере навигации снизу нет, а
  слева меню. Значение по умолчанию — телефонное, до символа прежнее.
- **Компьютер — `useIsDesktop()`** (от 1024 px, `DESKTOP_QUERY`), одна точка
  на всё приложение. Точки перехода переедут в `shared/ui` вместе с общими
  раскладками (PLAN.md Ф1.4).
- **Здесь нет предметной логики.** Правило «сколько слов в день», «кто
  ученик», «как считается балл» — в `domains/` (а до переезда — в `lib/`).
- **`localStorage` — только через `lib/storage`.** Приватный режим,
  переполнение и битый JSON дают запасное значение, а не падение экрана.
- **Адрес = «где я»** (`lib/useUrlState`): заход внутрь пушит запись в
  историю, возврат кареткой — заменяет. В PWA на телефоне свайп-назад — единственный
  способ вернуться, поэтому экран без адреса выпадает из навигации.
- **Смена экрана ждёт перерисовки** (`lib/viewTransition`, `domSettled`):
  React Router откладывает обновление через `startTransition`, и без ожидания
  браузер снимает два одинаковых кадра — анимация играет впустую.
- **Загрузка экрана — `useAsyncData`**, а не ручные `useState + useEffect +
  try/catch`: он отличает «пусто» от «не удалось загрузить» и даёт повтор.
- **Числительные — только `plural`.** «32 новых слов» выглядит почти
  правильно и поэтому живёт в интерфейсе годами.
- **Адрес поддержки — только `contacts`.** Второй экземпляр разойдётся.

## Как проверить

- `npm run build` и `npm run check` (границы, размер, линтер).
- `node scripts/smoke-navigation.mjs` — «назад»/F5 на внутренних экранах
  (`useUrlState`), нужен `npm run dev:test`.
- `node scripts/smoke-motion.mjs` — переходы между экранами (`viewTransition`).
- `node scripts/test-homework-suggest.mjs` — формы `plural` на 1/2/5/11/21/112.
- `node scripts/check-api-vercel.mjs` — сервер собирается без клиентского кода.
- `node scripts/check-types-drift.mjs` — типы базы совпадают со схемой
  тестовой базы.
- `node scripts/smoke-shell.mjs` — `shellInsets` и `useIsDesktop` в деле:
  раскладка на 390 / 820 / 1280, панель ввода «Диалога» в колонке у низа
  окна, смена ширины окна переключает раскладку.

## Решения и почему

- **Переезд из `src/lib` — `git mv` без правок поведения** (PLAN.md Ф1.3).
  Имена функций сохранены, поменялись только пути импорта.
- **`plural` вынесен из `lib/text.ts`**: в `text.ts` осталась сверка ответов
  (`answerMatches`, парная к SQL `norm_typed`) — это правило предметной
  области, оно переедет в свой домен.
- **`contacts` — сюда, а не в домен**: адрес поддержки нужен разбору ошибок
  базы (`shared/api`), а тот лежит на нижнем этаже.
- **`dbError.ts` → `api/errors.ts`, `gemini.ts` → `api/ai.ts`**: имена файлов —
  по архитектуре (§1), имена функций прежние, чтобы не трогать ~57 мест
  вызова в 22 файлах.
- **`AppError` — наследник `Error` с полем `code`** (наш `RECALL_*` или код
  библиотеки). Текст, `name` и `instanceof Error` прежние, поэтому экраны
  работают как раньше; `code` — для кода, которому важна причина.
- **Подписка вместо импорта аналитики**: прямой вызов `track` из клиента AI
  нарушал бы правило «shared импортирует только shared». Подписка поставлена
  до первого рендера — ни один запрос мимо воронки не проходит.
- **Клиент распознавания речи (`lib/transcribe.ts`) и серия сбоёв AI
  (`lib/aiHealth.ts`) остались в `lib/`**: по архитектуре это домен `ai`
  (§1), а не транспорт.
