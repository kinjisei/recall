# data — учебный контент: слова, уроки, тексты, тесты

## Простыми словами

Всё, что ученик учит, лежит здесь готовыми файлами, без базы: словари, уроки
грамматики, тексты, фразы для речи, тест уровня. Приложение читает их прямо из
сборки, поэтому контент работает без сети и не стоит ни запросов к базе, ни ⚡.

**Английский** — авторский: 60 уроков грамматики A1–C1, 147 неправильных
глаголов, 60 фразовых (476 фраз), 911 идиом из EFE, 3591 слово «База уровня»
из 4000 Essential Words, 60 фраз речи, тест уровня на 60 вопросов. 28 текстов
A1–C1 пока лежат в `features/reader/sampleTexts.ts` (переедут в `content/` —
PLAN.md Ф3.0).

**Испанский** целиком перенесён из Flutter-приложения Loro: 46 текстов,
31 диалог, 135 фраз, весь словарь A1–B2 (~4668 слов), 74 урока грамматики,
спряжения 14 времён, тест уровня на 60 вопросов. Исходного проекта Loro
(`d:\projects\spanish`) на компьютере больше нет — проверено 27.09.2026;
живая копия — только эта папка и её история в git.

## Правила, которые нельзя нарушить

- **Файлы словаря не трогаем**: 9512 слов, неудачная конвертация не
  откатывается. Испанские сверять с git-историей `src/data/spanish/` —
  исходного проекта Loro больше нет. Склейка, нарезка и чистка повторов паков
  живут в коде (`features/flashcards/CLAUDE.md`), а не в данных.
- **Контент — не код:** сторож описаний и сторож размера его не проверяют,
  правка контента не требует правки этого описания.

## Как проверить

- `node scripts/validate-exercises.mjs` (в CI) — структура упражнений:
  грамматика EN/ES, тренажёр окончаний, неправильные глаголы, тесты уровня
  (индекс ответа в диапазоне, варианты без дублей). Языковую правильность не
  проверяет.
- `node scripts/test-word-packs.mjs` (в CI) — состав каждого пака совпадает с
  данными.

## Решения и почему

- «Слово дня» — отдельный маленький файл: раньше Главная грузила ради одного
  слова весь словарь (~204 КБ gzip).
