# components — общие куски с предметной логикой: упражнения, шторки, итог раунда

## Простыми словами

Части экрана, которые нужны нескольким разделам сразу и при этом знают про
слова, упражнения или AI (поэтому они не в `shared/ui`, где только «кирпичи»
без смысла). Движок упражнений — общий для грамматики и материалов
преподавателя. Шторка слова открывается по тапу в любой читалке: перевод в
контексте, транскрипция, «в колоду», разбор предложения. Экран итога раунда и
разбор ошибок с кнопкой «Почему?» — одни на все игры и упражнения.

Когда человек ошибается в упражнении, мы не показываем правильный ответ сразу:
сначала подсказка, ГДЕ ошибка, и вторая попытка. Готовый ответ, выданный
сразу, закрывает работу: человек сверяет две строки и идёт дальше, не найдя
ошибку сам.

При переезде (PLAN.md Ф3) эти куски разойдутся по своим разделам и доменам.

## Правила, которые нельзя нарушить

**Самокоррекция: сперва ГДЕ ошибка, ответ — потом**

- Ошибся — подсказка о МЕСТЕ ошибки и вторая попытка; правильный ответ — после
  неё или по кнопке «Показать ответ».
- **Правило и тексты подсказок — `lib/selfCorrect.ts`, одно место на все
  упражнения:** выбор, вписать, собрать предложение (`exercises.tsx`),
  «Собери фразу» (`features/words/SentenceBuilder`) и диктант
  (`features/words/DictationMode`).
- **Исключение — «Соедини пары» и «Верно / Неверно» (макет u5): второй
  попытки нет.** Из двух кнопок вторая попытка — готовый ответ; у пар итог
  по каждой паре и есть разбор (балл — за каждую пару, сервер считает так же).
- **Решение «показывать ли ответ» принимает `shouldReveal`, и зовут её ВСЕ
  пять мест.** Новое упражнение подключает `shouldReveal`, а не пишет своё
  сравнение. Сначала было иначе: функция существовала, тест её проверял, а
  экраны повторяли `n >= ATTEMPTS_BEFORE_ANSWER` каждый у себя — тест стерёг
  код, которого в продукте не было.
- **Балл — по ПЕРВОЙ попытке.** `onAnswered`/`onGiven` вызываются ровно один
  раз: иначе «8 из 10» перестаёт значить «знает восемь», а сервер (он
  пересчитывает балл из `given`) начислит за исправленное. Вторая попытка —
  для обучения, не для оценки.
- **Подсказка не восстанавливает ответ.** Говорим позицию и количество
  («первые 2 слова верны», «слов должно быть 4»), но не содержание — иначе это
  тот же ответ, только с лишним нажатием.
- **Перепроверка слов (`features/flashcards/WordCheckRunner`) второй попытки
  НЕ получает** — это проверка знаний для преподавателя, а не тренировка;
  вторая попытка завысила бы его отчёт.

**Обратная связь**

- Отзыв (`FeedbackSheet` + `lib/feedback.ts`) хранится событием в `events`
  через `track_event` — отдельной таблицы нет намеренно: сбор работает сразу
  после деплоя, без правки схемы. Владелец читает через RPC `admin_feedback`
  (блок в `/admin`). Вход: меню под аватаром и «Настройки». Текст отзыва —
  черновик до отправки (Ф1.14, `shared/lib/useDraft`).

## Как проверить

- `node scripts/test-material-exercises.mjs` (чистый, в CI) — правило второй
  попытки и «подсказка не выдаёт ответ»: краснеет, если подсказка начнёт
  возвращать ответ или его слова.
- `node scripts/smoke-assignment-review.mjs` — упражнения в задании ученика,
  разбор ошибок.
- `node scripts/smoke-feedback.mjs` — отзыв доходит до блока в `/admin`.

Смоукам нужен `npm run dev:test` (`scripts/CLAUDE.md`).
