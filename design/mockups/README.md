# Макеты Claude Design

Сюда владелец сохраняет понравившиеся макеты (PLAN.md Ф5.1, журнал п.22); по
ним делается редизайн (Ф5.2). Промпты — `docs/design/prompts.md`, опись
интерфейса — `docs/design/ui-inventory.md`.

## Как сохранить

1. В Claude Design — экспорт **HTML** (один самостоятельный файл). Это главный
   формат: из него программист возьмёт точные цвета, размеры и шрифты. PDF —
   тоже можно, для просмотра.
2. Переименовать по правилу ниже и положить сюда, в `design/mockups/`.
3. По желанию — скриншоты PNG для быстрого просмотра, с тем же началом имени.
4. Отметить статус в таблице ниже и сказать Claude «закоммить макеты». В git —
   только последняя версия каждой группы: промежуточные попытки не хранить.

## Правило имён

`<код>-<что>[-<экран>-<тема>][-v<N>].<html|pdf|png>`

- **код** — из `docs/design/prompts.md`: `s1`…`s4` · `t1`…`t9` · `n1` ·
  `u1`…`u4` · `d0`…`d6`;
- **что** — как в столбце «Файл» таблицы: `t2-schedule`, `d2-new-lesson-panel`;
- **экран и тема** — только у скриншотов одного кадра: `-day-dark`,
  `-week-light`;
- **v2, v3** — новая попытка после правок; утвердили новую — старую удалить;
- только латиница, строчные буквы, цифры и дефисы — без пробелов и кириллицы:
  на таких именах путаются Git и Windows.

Примеры: `t2-schedule.html` (весь экспорт группы: все кадры обеих тем),
`t2-schedule-day-dark.png`, `d1-schedule-week-v2.html`.

⚠️ **Не сохранять как `.zip` и `.dc.html`** — такие файлы git молча не берёт
(`.gitignore`: так когда-то решили не хранить прототипы Omelette). ZIP —
распаковать, `.dc.html` — переименовать в `.html`.
